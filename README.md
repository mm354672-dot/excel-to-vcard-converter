# 📊 Excel to vCard (.vcf) Leads Converter для CRM и Смартфонов

Профессиональный скрипт автоматизации для отделов продаж и интернет-маркетологов. Позволяет мгновенно конвертировать базы клиентов из таблиц Excel (.xlsx) в международный формат контактов vCard (.vcf).

## 💼 Какую бизнес-задачу решает проект?
Менеджеры по продажам часто получают базы лидов в формате Excel. Вручную переносить сотни номеров в мобильный телефон или CRM для обзвона и рассылок в мессенджерах — это потеря рабочих часов. 
Этот скрипт автоматизирует процесс: он очищает номера от мусорных символов, приводит их к единому международному стандарту (+7...) и упаковывает в один файл. Этот файл можно за 1 клик импортировать в **amoCRM, Битрикс24, Google Contacts, iPhone или Android**.

## 🔥 Ключевые фичи:
* **Умный поиск колонок:** Скрипт сам находит колонки с именами и телефонами, даже если они названы по-разному ("Имя", "ФИО", "Name", "Телефон", "Phone").
* **Валидация номеров:** Автоматически очищает телефоны от скобок, пробелов, дефисов и конвертирует "восьмерки" в международный формат `+7`.
* **Zero-Dependency импорт:** Создает чистый vCard 3.0 файл, совместимый абсолютно со всеми современными смартфонами и CRM.

## 🛠️ Стек технологий:
* Python 3.8+
* Pandas & OpenPyxl (для высокоскоростной обработки таблиц данных)

## 🚀 Быстрый старт:
1. Установите зависимости: `pip install pandas openpyxl`
2. Положите вашу Excel-таблицу в папку со скриптом.
3. Запустите скрипт. На выходе вы получите файл `business_leads.vcf`, готовый к импорту.
